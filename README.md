# ⚛️ React Learning Projects

A collection of projects built while learning **React**, **JavaScript**, and **TypeScript**. This repository showcases hands-on practice with core frontend concepts, component-based architecture, state management, API integration, and modern development tools.

## 🚀 What You'll Find

* React fundamentals
* Functional components and hooks
* State and props management
* Forms and user interactions
* Routing with React Router
* API integration and data fetching
* TypeScript with React
* Responsive UI development
* Reusable components and project structure

## 📂 Project Structure

```text
react-learning-projects/
├── MEMORY-CARD/
├── project-2/
├── project-3/
├── project-4/
└── README.md
```

Each folder contains an independent React application focused on a specific concept or feature.

## 🛠️ Tech Stack

* React
* JavaScript (ES6+)
* TypeScript
* HTML5
* CSS3
* Vite
* npm

## ⚡ Getting Started

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to a project folder:

```bash
cd project-name
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
